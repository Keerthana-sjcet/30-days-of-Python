# 30 DAYS OF PYTHON
  Each folder represents **one day**
- Each day contains:
  - A `README.md` with the problem description
  - Python solution files submitted by participants

---

## 🗓️ How the Challenge Works

- One Python problem is assigned each day
- Participants solve the problem independently
- Solutions are submitted to the corresponding day folder
- Team members are encouraged to discuss logic and improvements
- Emphasis is placed on readable code and proper documentation

---

## 🧩 Contribution Guidelines

- Submit solutions only in the assigned day’s folder
- Follow basic Python coding conventions
- Write clean and readable code
- Avoid direct copying; logical discussions are encouraged
- Review teammates’ solutions and provide constructive feedback

---

## 🛠️ Technologies Used

- Python
- Git & GitHub
- Markdown
- Any Python-supported IDE (VS Code, PyCharm, etc.)
